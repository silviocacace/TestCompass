# Quick Start Guide

This guide introduces the basic workflow in TestCompass and helps you understand how its modelling-based approach supports early testing.

## 1. Understand the Approach

TestCompass is based on early Model-Based Testing (eMBT). The approach makes expected behaviour explicit through models, helping teams clarify requirements, explore risks and establish a shared understanding before development begins.

Read the [eMBT Approach](eMBT-approach.md) to learn more.

## 2. Create or Explore a Behavioural Model

Start by exploring how TestCompass represents expected behaviour through explicit models.

See [Modelling](modelling.md) for more information.

## 3. Use AI-Assisted Features

TestCompass includes AI-assisted capabilities to support model creation and reflection:

- [AI-Assisted Model Creation (AAMC)](aamc.md)
- [AI-Assisted Model Reflection (AAMR)](aamr.md)

These features support the modelling process while keeping the tester involved in reviewing and refining the result.

## 4. Generate Tests and Analyse Coverage

Once a model is available, explore how TestCompass supports test generation and coverage analysis.

Read [Test Generation & Coverage](test-generation.md).
