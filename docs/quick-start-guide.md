# Quick Start Guide (QSG)

For a guided, hands-on introduction and your first steps with TestCompass, use the interactive **Quick Start Guide** available directly inside the application via the **Help menu** and the **Book icon**.

---

## How the Quick Start Guide Relates to This Documentation

- **Quick Start Guide (In-App):** Explains the *how* — practical, step-by-step instructions for using the TestCompass user interface, creating your first model, and generating basic tests.
- **GitHub Documentation (This site):** Explains the *why* and the *what* — conceptual guidance, detailed features, eMBT philosophy, integration guidelines, and AI-assisted capabilities (AAMC & AAMR).

Together, they provide everything you need to master TestCompass, from your very first click to advanced continuous testing workflows.
